<h1 align="center">Pricing Rules Relationship for Craft Commerce</h1>


Craft Pricing Rules Relationship is a field that creates relationships between Craft Commerce Pricing Rules and elements. It fills the gap between Craft Commerce's built-in pricing rule management and Craft's built-in element relationships, allowing store managers to easily link pricing rules to any element type.

## Features
- **Seamless Integration** – Connects Craft Commerce Pricing Rules directly to any element type
- **Easy Selection** - User-friendly field interface for selecting and managing pricing rule relationships
- **Flexible Relationships** – Link pricing rules to entries, products, categories, or any custom element
- **Commerce-Ready** - Built specifically for Craft Commerce pricing workflow optimization

## Perfect For
- Associating pricing rules with specific content
- Linking catalog pricing rules to marketing campaigns
- Managing pricing strategies across your commerce site
